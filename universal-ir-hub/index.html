Universal IR Hub

ESP8266 firmware for decoding NEC infrared commands and home automation control

Author · Namit Seth ESP8266 · C++ GitHub

Project Overview

The Universal IR Hub is an ESP8266-based system built to interpret and relay infrared remote control signals, especially undocumented NEC protocol payloads, into a smart home control flow.

Core capabilities

  • Reverse-engineered undocumented NEC IR payloads for broad device compatibility.
  • Custom firmware optimized for memory-limited ESP8266 hardware.
  • Integration with smart home ecosystems via Sinric Pro.
  • Support for remote commands without reliance on common IR libraries.

Technology used

  • ESP8266 microcontroller
  • C++ firmware
  • NEC infrared protocol decoding
  • Sinric Pro / smart home MQTT-style bridge

Implementation details

The project includes a custom IR decoding engine that processes raw NEC payloads, eliminates the need for generic IR libraries, and preserves memory by handling the protocol in a lightweight, register-efficient way.

Example behavior: the hub can identify a button press, filter invalid pulses, and publish a standard payload to the home automation gateway.

What I learned

  • Working with undocumented protocol patterns and signal timing.
  • Writing embedded firmware for constrained memory environments.
  • Bridging legacy hardware controls into modern smart-home services.
  • Testing IR signal reliability across different remotes.
