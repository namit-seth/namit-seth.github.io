Live Multiplayer Treasure Hunt Game

A Flask-based web app for competitive team events with live play and persistent scoring

Author · Namit Seth Flask · SQL GitHub

Project Overview

This project is a real-time web-based treasure hunt platform built in Flask with SQLite persistence. It supports multiple concurrent teams, live clue delivery, and structured score tracking for event-based gameplay.

Core features

  • Team-based gameplay for up to 10 concurrent groups.
  • Live clue and challenge delivery via web sessions.
  • Score and time tracking stored in the database.
  • Session stability for simultaneous player interactions.

Technical stack

  • Backend: Python Flask
  • Database: SQLite
  • Frontend: HTML, CSS, JavaScript
  • Session management: Flask sessions

Challenges solved

  • Prevented database locks during simultaneous login and progress updates.
  • Maintained consistent game state for every active team.
  • Handled result calculations and leaderboard updates safely.

What I learned

  • Managing concurrent users in a lightweight Flask app.
  • Resolving race conditions in SQL transactions.
  • Designing game flows that feel immediate and fair to all teams.
