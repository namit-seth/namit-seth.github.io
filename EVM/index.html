Building a Simple Electronic Voting Machine (EVM) with Arduino

Author · Namit Seth Embedded & UI

Electronic Voting Machines (EVMs) are a modern replacement for traditional ballot paper-based voting systems. They offer faster results, reduced human error, and are environmentally friendly. In this project, I built an Arduino-based EVM (V2) that demonstrates a complete voting flow with live vote tallying and results shown on an LCD screen.

Project objectives

  • Allow two candidates to receive votes via push buttons.
  • Display a real-time voting interface on the LCD.
  • Show the winner once voting ends.
  • Use simple, easily breadboarded components that can also be simulated in TinkerCAD.

Components used

  • 1 × Arduino Uno
  • 1 × 16×2 LCD display
  • 3 × Push buttons (for voting)
  • 1 × Push button (to end voting & show result)
  • 3 × LEDs (visual vote feedback)
  • 1 × Buzzer (confirmation sound)
  • Resistors: 220Ω, 1kΩ
  • Breadboard and jumper wires

How it works

  1. Initialization: The LCD shows a welcome message and sets all vote counters to zero.
  2. Voting process:
    • Each push button corresponds to a candidate.
    • On press:
      • The candidate’s vote counter increments.
      • The LED blinks and the buzzer emits a short tone for haptic-style feedback.
  3. Ending voting:
    • Press the “Result” button to stop voting.
    • The LCD displays total votes for each candidate and highlights the winner.
    • In case of a tie, the LCD clearly indicates it.

Code overview

The logic is written in Arduino’s C-style syntax. You can browse the full .ino file here.

Sample input handling:

if (digitalRead(button1) == HIGH) {
  votesA++;
  tone(buzzer, 1000, 200);
  digitalWrite(led1, HIGH);
  delay(200);
  digitalWrite(led1, LOW);
}

Sample LCD output:

lcd.setCursor(0, 0);
lcd.print("Votes A: ");
lcd.print(votesA);

What I learned

  • Designing user feedback loops with LCD, LEDs, and buzzer.
  • Button debouncing and reliable digital input handling.
  • Structuring embedded logic for clarity and maintainability.
  • Iterating quickly with TinkerCAD before wiring on real hardware.

Future improvements

  • Password-protected access to the result function.
  • Using EEPROM to persist votes across power cycles.
  • Replacing mechanical buttons with capacitive touch inputs.
  • Adding SD card logging for an auditable vote trail.
