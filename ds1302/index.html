DS1302 RTC Interface

Real Time Clock Integration for Embedded Systems

Author · Namit Seth Arduino · RTC GitHub

Project Overview

This project demonstrates how to interface the DS1302 Real Time Clock (RTC) module with a microcontroller for maintaining persistent time and date. The DS1302 is a low-power serial real-time clock with a simple 3-wire interface, making it well-suited for Arduino and other embedded systems where accurate timekeeping is needed across power cycles.

Hardware Used

  • DS1302 RTC module — Real-time clock IC with battery-backed SRAM
  • Microcontroller — Arduino or compatible board (e.g. Arduino Uno, Nano)
  • Crystal oscillator — 32.768 kHz (typically on the RTC module)
  • Backup battery — Coin cell (e.g. CR2032) for time retention when power is off
  • Breadboard and jumper wires — For prototyping and connections

Working Principle

The DS1302 communicates via a 3-wire serial interface (data, clock, and chip select), which keeps pin usage low on the microcontroller. Time and date (seconds, minutes, hours, day, month, year) are stored in internal RTC registers and can be read or written by the host. A backup battery keeps the RTC running and maintains the time during power loss, so the system can resume with the correct time when power is restored.

Code Implementation

The firmware typically covers: RTC initialization, setting the time (e.g. once on first run or via serial command), reading the time from the RTC registers, and displaying or using the time in the rest of the embedded project (e.g. on an LCD, for logging, or for scheduling).

Typical flow — initialization and pin setup:

#include <RTClib.h>  // or DS1302 library

#define RTC_CLK  5
#define RTC_DAT  6
#define RTC_RST  7

void setup() {
  Serial.begin(9600);
  rtc.begin();
  // Optional: set time once if not already set
  // rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
}

Reading and using the current time:

void loop() {
  DateTime now = rtc.now();
  // Display or use: now.year(), now.month(), now.day()
  //                 now.hour(), now.minute(), now.second()
  Serial.print(now.year()); Serial.print("/");
  Serial.print(now.month()); Serial.print("/");
  Serial.println(now.day());
  delay(1000);
}

Applications

  • Digital clocks — Standalone or with LCD/OLED display
  • Data logging systems — Timestamping sensor data to SD card or serial
  • Embedded scheduling systems — Triggering events at specific times
  • Automation projects — Time-based switching, alarms, or reminders
